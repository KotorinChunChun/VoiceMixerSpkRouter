# VoiceMixerSpkRouter v1.0.13 UI設計・実装報告

2026-11-08 実装・検証完了。参照：[VoiceMixerMicRouterの変更](codex://threads/01a14fe4-96c6-7461-ab4d-da5e84049570)。

## 今回取り入れる操作

- 右上の「設定」は、オーバーレイが表示されている間、設定画面の開閉や音声モードにかかわらず既存の強調色で表示する。表示を切り替える操作やクリック範囲は現状どおり。「常時着色」はオーバーレイを常時表示する意味ではない。
- 「基本設定」「キー設定」の各タブに「初期値に戻す」を置く。現在のタブの編集値だけを初期値に戻す。「適用」で保存・反映し、適用せず閉じた場合は破棄する。適用エラー時は保存済み設定と音声経路を保持する。
- 基本設定の初期値：再生デバイス入力は「既定のデバイス」、取得対象アプリは「未選択」、出力1は「既定のデバイス」、出力2は「未選択」。初期起動は取得停止・両出力OFF。タブのリセットは稼働中のモードや出力ON/OFFを直接切り替えず、適用時には既存の経路検証を通す。同一デバイスへのループを許可しない。
- 認証トークン、ブラウザーの接続設定、自動起動は基本設定リセットの対象から外す。既存の保存値は更新だけでは書き換えない。キー設定は既存の初期キー割当、共存／上書きと有効状態に戻す。

## 別判断にする項目

- MicRouterのRVC・効果音・出力3・押下中の出力切替はSpkRouterには移植しない。
- 左右別の修飾キーは現行の保存形式とキー監視を変えるため、今回の配色・リセットから分ける。取り入れる場合は既存ONを「左|右」に移行し、取得モード切替での単独修飾キーの扱いを別途決める。
- 未選択の項目を隠す場合は、未選択から再選択できる入口を残す。SpkRouterの現行表示を維持し、候補の並びや非表示条件をこの変更に合わせて一律には変えない。既存のボタン幅と余白は維持する。

## 受入条件

- 設定窓を開閉しても設定ボタンの背景色が変わらず、停止・取得中ともクリックできる。
- 各タブで初期化しても別タブの編集内容・保存値・音声経路は適用前に変わらない。適用・キャンセル・経路エラーをそれぞれ確認する。
- 新規設定の出力はOFFで、取得元と同じデバイスへの転送は拒否される。既存設定で再起動しても設定は保持される。

保存済み設定・親カタログ・公開物は変更しない。
