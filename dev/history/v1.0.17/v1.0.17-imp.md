# VoiceMixerSpkRouter v1.0.17

- [x] heapless 0.9.4へ移行し、flacencの容量エラー処理を合わせる。
- [x] 合成PCMのFLAC保存・読み戻し、音声経路、接続、停止を検証する。
- [x] 配布候補の主要操作と更新を検証し、タグ・配布物・SHA-256を照合する。
- [x] 設定のタブ切替、下書きの適用・破棄を隔離CLIから自動検証できるようにする。

Windowsの通常構成でheapless 0.9.4が選ばれることを確認した。公式flacenc 0.5.1に互換修正を適用し、FLAC録音の短い最終ブロックも保存できるようにした。更新補助に.NET 10.0.15を同梱する。配布版にはv1.0.15の経路衝突と待機理由、認証トークンの伏せ字、およびv1.0.16の実装を含める。隔離テストCLIは開発ビルド専用。

Win32の管理試験で、クライアントが読む前に管理パイプが強制切断され、返信が欠けることがあった。リクエストごとに使うハンドルを閉じるよう改め、遅延読み取りと60回の連続接続を検証した。設定表示時のプロセス情報の取得は、一覧で使う項目に絞った。

v1.0.14から更新するときは旧版のパイプに接続するため、更新補助とインストーラー試験は、要求を送る前に読み取りを開始するようにした。

- 音声エンジン162件、SpkRouter通常64件、起動・保存・停止13項目、管理契約16項目、実EXEの設定12項目、ブラウザ拡張31件、更新補助11件が成功。
- Win32の画面・設定・合成フック試験8件も成功。
- 隔離CLIは40項目が成功。基本設定とキー設定を切り替えたときの下書き保持、同じタブでの適用、閉じるときの破棄、ポート0と古い下書きの拒否、保存失敗時の保持をJSONで確認した。合成データを使用し、並行起動した通常版の試験プロセスと試験用設定のハッシュが変わらないことを照合した。
- 配布用EXEを実画面で開き、Ctrl+Tab、マウスによるタブ移動、伏せ字と循環予告、適用、閉じる操作を確認した。CLI追加前後の配布用EXEのSHA-256は一致した。配布版の画面と開発用CLIの確認を同じ版のログに残した。
- 実機の聴感、外部ブラウザーの実タブ、物理キーの押下は未確認。画面では循環予告と適用結果が同時に出る際、2行目の下端が一部欠ける。保存結果は自動試験でも確認した。
