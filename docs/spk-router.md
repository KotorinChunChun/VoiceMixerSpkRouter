# VoiceMixerSpkRouter

Windowsの再生デバイス・アプリ・ブラウザ音声を選び、2台の再生デバイスへ転送する常駐アプリです。現在版はv1.0.11。本体・マイク版とは設定と版管理が独立しています。本書をSpkRouterの現行仕様の正本とします。

## 用途

再生デバイス、特定のアプリ、ブラウザタブの音声から取得元を一つ選び、2つの再生デバイスへ転送します。配信・録音先への共有と、自分のモニタリング先を、このツールのオーバーレイやキー操作で切り替えたいときに使えます。

例えば、アプリやブラウザの音を仮想オーディオデバイスなどへ送り、OBSなどの配信・録音ソフトで受け取ることができます。また、普段は聞いていない仮想デバイスで鳴っている音を取得し、自分のスピーカーやヘッドホンへ一時的に転送することもできます。

出力1・2は個別にON/OFFできます。例えば、出力1を配信・録音側への転送、出力2を自分のヘッドホンに設定し、必要なときだけモニターをONにできます。配信・録音ソフト側では、転送先の音声を受け取る設定を別途行ってください。

出力のON/OFFは、このツールからの転送に対する操作です。元のアプリや再生デバイスの音量・ミュート・再生先は変更しません。自分への出力をOFFにしても元の音がスピーカーで再生されていれば聞こえるため、聞きたくない場合は元の再生先も合わせて設定してください。ブラウザ拡張では、必要に応じて対象タブの「同時再生」もOFFにします。

OBSなどの配信・録音ソフトにも音声を選ぶ機能があるため、それらのソフト上で足りる場合は本ツールは必須ではありません。本ツールのオーバーレイやキーで取得元を切り替え、出力先を操作したいときに利用できます。

## 起動と設定

```powershell
cd C:\develop\VoiceMixerSpkRouter
pwsh -NoProfile -File .\dev\scripts\Start-SpkRouter.ps1 -Debug -Mode Settings
```

新規導入は停止・出力2系統ともOFF・常時表示です。設定画面は「基本設定」「キー設定」のタブを切り替えて使います。Ctrl+Tabでも切り替えられます。

基本設定は「オーバーレイ表示」「ログイン時のモード」、入力スピーカー、入力アプリ、入力ブラウザ、出力1・2の順です。共通の項目名はMic版と揃え、出力は用途名・デバイス・「有効」を選びます。用途名は前後の空白を除く1〜24文字で、同じ名前も使えます。適用すると設定画面・トレイ・オーバーレイ・循環エラーへ反映します。長い用途名は常駐表示で省略しますが、全角5文字とON/OFFは表示できます。

ログイン時は「前回のモード」または再生デバイス・アプリ・ブラウザ・送信停止を指定できます。CLIの明示モード指定はこの設定より優先します。使用OFFの取得元を指定した場合は停止で起動します。用途名・キー・表示・起動方法だけの変更では音声デバイスを再起動しません。

各入力の「使用する」をOFFにすると、設定欄と対応するキー欄をグレーアウトし、オーバーレイの候補を隠します。選択中の入力をOFFにして適用すると取得・転送を停止します。デバイス・キー・接続設定は保持し、再ONで使用できます。旧設定ではすべてONとして従来の4択を維持します。ブラウザを使用OFFにした場合は待受も停止し、再ONで復旧します。

コンボボックスの一覧は閉じた欄と同じ幅で展開します。長いアプリのフルパスは選択後の詳細欄で確認できます。

下部ボタンは「適用」「閉じる」です。「適用」は音声反映と設定保存の成功後も、同じタブを開いたままにします。適用中も画面の処理を継続し、編集操作は一時的に無効にします。失敗した場合は旧設定・旧経路への復旧を試み、同じ画面に編集内容と失敗理由を残します。「閉じる」は最後の適用以降の未保存内容を破棄し、常駐は続けます。

設定画面を開いている間も、適用済みの割当キーで取得元・停止・表示を変更できます。未適用の入力とキー割当は保持します。未編集の表示方法は表示キーの変更に追従し、編集中ならその入力を残します。適用中は最後のキー操作を処理の完了後に反映します。トレイは「設定…」以外、常駐表示やCLIからのモード変更は、設定画面を閉じるまで制限します。設定を開く操作・ダブルクリックは既存画面を復元し、重複作成や不要なフォーカス移動をしません。更新・復旧用のCLI `--stop` は利用できます。

基本設定の下部にある「GitHub（公開リポジトリ）」は、[専用リポジトリ](https://github.com/KotorinChunChun/VoiceMixerSpkRouter)を既定ブラウザで開きます。キー設定の下部には、共存・上書きの動作を説明するラベルがあります。

## 操作とキー設定

| 操作 | 既定のキー | 動作 |
|---|---|---|
| オーバーレイ表示切替 | なし | オフ→数秒表示→常時表示→オフ |
| 設定画面を開く | なし | 設定を開く、既存画面を復元 |
| 再生デバイスへ切替 | Shift+F1 | 指定した再生デバイスの音声を取得 |
| アプリへ切替 | Shift+F2 | 指定アプリの再生音を取得 |
| ブラウザへ切替 | Shift+F3 | Chrome/EdgeのVoiceMixer拡張が送るタブ音声を取得 |
| 停止へ切替 | Shift+F4 | 取得と転送を停止 |

取得元は単一選択です。選択中の取得キーを再度押すと停止し、停止の再押下では停止を維持します。出力1・2のON/OFFは独立して保持します。出力にキー・P2Tは設けません。全出力OFFでも選択入力の取得は続けます。停止では取得・転送の両方を止め、使用ONのブラウザ待受と常駐だけを維持します。

キー設定は上表の順で並べ、オーバーレイの行に合わせて「設定」と「入力」をセパレータで区切ります。各行は「有効」、Ctrl・Shift・Alt・Windows、主キー、モードの順です。主キーは「なし」・A〜Z・F1〜F24から選び、修飾キーなしも使えます。無効な行は修飾キー・主キー・モードをグレーアウトします。「なし」を選ぶと有効もOFFとなり、有効だけOFFなら選択を保持します。未割当の行も「有効」をチェックしてからキーを選べます。重複や不正値は拒否します。旧4行設定の独自割当・無効状態と保存済みAlt割当は保持し、新しい2行は未割当で補います。Shiftの既定値は保存済みの独自設定を上書きしません。

各キーのモードは「共存／上書き」です。共存が既定で、旧設定も共存として扱います。共存では従来どおり、他アプリやリモートPCにも同じ入力を渡します。上書きでは、一致した主キーの押下・長押し・解放を可能な範囲で後続へ渡さず、SpkRouterの操作に使います。押した後で修飾キーを先に離した場合や割当を変更した場合も、主キーの解放まで対応を維持します。使用OFFの取得元はキー検出から外します。

専用スレッドの低レベルフックを使い、長押しで連続切替せず、合成入力は操作対象にしません。OSのキー予約は使いません。Ctrl+Alt+DeleteなどOSが保護する操作、権限の異なるアプリ、先に処理する他のフックまで抑止する保証はありません。Alt/Windowsを含む上書きでは単独メニューの起動を防ぐ補助入力を使いますが、修飾キーの押下・解放自体は通し、押しっぱなし状態を作りません。

通常権限のMSTSCが前面の場合も、共存・上書きとも同じ検出を使います。前面に来た直後と以後約500msごとにフックの順序を更新し、MSTSC中は非同期キー状態による補正をしません。昇格したMSTSC・セキュアデスクトップ・他のリモートクライアントは保証対象外です。実際の接続確認は[検証記録](../dev/testing/spk-router-results.md)と区別します。

## 常駐表示とトレイ

常駐表示はMic版と同じ横幅464pxで、主画面の作業領域の右端から80px、上端から230pxの位置から開始します。Mic版の初期位置（右・上80px、高さ130px）の20px下へ並べ、重なりを避けます。最前面ですが他アプリの入力フォーカスを奪いません。左ドラッグで移動でき、起動中の表示切替・モード変更でも位置を維持します。4px以上動いた押下ではクリック操作を発火させません。

左端にオレンジのテーマバーを置き、上部の見出しを削除して「設定」「入力」「出力」の行を上へ詰めています。同じ行のボタン幅を揃え、入力は使用ONの候補と停止だけを均等に並べます。全入力OFFでは停止だけを表示します。出力は2つの独立トグルです。選択中・ONは明るい背景、OFFは暗い背景で表示します。押せる領域は指カーソル、背景・ドラッグは移動カーソルです。ラベルと余白は操作しません。ダブルクリックで設定を開けます。

表示は次の3段階で保存します。設定画面、トレイ、割当キー、常駐表示の表示ボタンは同じ設定を操作します。

- オフ：即座に消し、モード変更・起動・エラーでも表示しません。
- 数秒表示：状態変更から4秒表示し、残り4→3→2→1秒を表示します。定期状態・メーター・秒数更新、マウスを重ねる操作では再表示や期限延長をしません。ドラッグ中は期限を延ばします。
- 常時表示：表示を維持します。

割当済みキーは修飾キーを省いて全操作へ表示し、未割当は角括弧ごと省略します。エラー時だけ説明行を追加します。描き終えた画像を一括転送し、定期更新だけで全体を描き直しません。トレイアイコンは白い文字とオレンジ系の背景で、取得元をD/A/B、停止をSで区別し、設定画面にも表示します。

入力メーターは各候補の真下、出力メーターは出力1・2のそれぞれの真下に表示します。非選択の入力と無効な出力には「無効」、選択中の準備・接続待ち・障害には「準備中」「待機中」「エラー」を同じ場所へ表示します。非選択の入力を追加で録音しません。

メーターは既存の音声イベントを使い、直近約1秒を50ms単位の20枠で表示します。入力は緑、出力は青、0dBFS以上は赤、欠測は空欄です。出力1・2を別々に計測し、無効なノードのイベントは集約しません。全出力OFFでは両出力が無音、取得停止では入力も両出力も無音です。OS全体の音量を示すものではなく、別の録音・取得を始めません。RVC専用の遅延表示・ノイズ処理は持ちません。

## ブラウザ音声

既存のVoiceMixer Edge PCM拡張をChromeでも使用できます。基本設定のブラウザ欄に「インストール案内」「設定案内」のリンクを置き、それぞれオフライン案内の該当箇所を既定ブラウザで開きます。ブラウザ使用OFFでも案内は利用できます。[導入](spk-browser-capture.html#install)・[設定](spk-browser-capture.html#setup)と、拡張共通の操作を扱う[拡張ガイド](edge-extension.md)を参照してください。

1. SpkRouterのポート・認証トークンを拡張の共通接続設定へ設定します。接続先は `127.0.0.1`、初期ポートは `18766`、トークンは初回生成です。
2. 対象タブのカードのキーをSpkRouterのストリームキーと一致させます。初期値は `spk-router` です。
3. 拡張でキャプチャを開始し、SpkRouterのブラウザ取得を選びます。

SpkRouterはブラウザのキャプチャ許可を代行しません。接続前・タブ停止中は音声待ちとなります。他の取得元や停止から戻る場合は古いバッファを捨てて再開します。同じブラウザでは拡張のポートとトークンはタブ共通です。本体・Runnerと異なる待受ポートを使ってください。待受の障害はブラウザモードで扱い、再生デバイス・アプリ取得へ波及させません。

## デバイスとアプリ

各一覧は「未選択」「既定のデバイス」「既定の通信デバイス」を先頭に置き、個別デバイスと未接続の保存先を名前順に並べます。同名の元の順と選択IDは保持します。「再読込」は候補だけを更新し、未保存の編集を変えません。

通常／通信の既定は論理IDで保存し、OSの割当へ約2秒ごとに追従します。個別デバイスはID固定です。未接続時も保存先を残し、別デバイスへ勝手に切り替えません。OFFの出力が未接続でも他の経路は止めません。

取得元とONの出力が同じ実デバイスなら循環エラーで送信を止めます。同じ保存IDを2つのON出力へ選ぶことも拒否します。異なる論理IDが同じ実デバイスを指す場合は出力1を優先し、重複送信だけを抑止します。この場合も保存した両出力のON/OFFは変更しません。

アプリは実行ファイルの絶対パスで記録し、終了・再起動と同じ実行ファイルの複数プロセスへ追従します。SpkRouter自身は対象にできません。元アプリや元デバイスの音量・ミュートは変更しません。ブラウザの元音は拡張の同時再生設定で確認してください。

## 配備と自動起動

```powershell
cd C:\develop\VoiceMixerSpkRouter
pwsh -NoProfile -File .\dev\scripts\Install-SpkRouter.ps1
pwsh -NoProfile -File .\dev\scripts\Start-SpkRouter.ps1 -Mode Settings
```

EXE・利用手順・オフライン案内・ビルド済み拡張を `release/SpkRouter/` へ配置します。拡張フォルダーは `browser-extension/` で、Chrome/Edgeへの登録は案内に沿って行います。配備前に `npm --prefix .\browser-extension run build` で拡張を生成してください。既存設定とStartupを保持して更新し、停止・退避・ビルド・配備・単一起動を順に確認します。更新ごとに独立版番号の3桁目だけを1増やし、上位桁は明示指示時だけ変えます。

自動起動登録は配備時の `-Startup`、直ちに起動する場合は `-Start` を明示します。マイク版のStartupリンクとは別です。解除はスタートアップフォルダーの `VoiceMixer Spk Router.lnk` を削除します。

設定は配備先の `spk-settings.json`、状態は `spk-status.json` です。デバッグも同じ設定を使います。旧表示boolはON→常時表示、OFF→オフへ移行し、新しい表示指定を優先します。設定は認証トークンを含むためGit・公開成果物へ入れません。

## 開発・検証

[内部構造と検証手順](architecture/spk-router.md)を参照してください。`--check device|application|browser|stopped` は保存設定で10秒診断し、常駐とは排他です。待機・準備中・エラーで終わった場合は未完了として失敗を返します。実装・自動試験・実接続・ユーザーの聴感確認は分けて[検証記録](../dev/testing/spk-router-results.md)へ残します。
