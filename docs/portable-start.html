VoiceMixerSpkRouterの使い方

Windows 11の64ビット版向けです。Rust・Node.js・PowerShell 7のインストールは不要です。

どんなときに使う？

アプリやブラウザの音を選び、配信・録音用の仮想オーディオデバイスなどと、自分のヘッドホンなどへ転送できます。普段は聞いていない仮想デバイスの音を、一時的に自分でモニターしたいときにも使えます。

出力1・2は個別にON/OFFできるので、配信・録音用をONにしたまま、自分用のモニターだけをOFFにすることもできます。配信・録音ソフト側でも、転送先の音声を受け取る設定が必要です。

この操作では元アプリの再生先や音量は変わりません。元の音がスピーカーで鳴っているときは、モニター用の出力をOFFにしても聞こえます。聞きたくない場合は元の再生先も設定してください。ブラウザ拡張では、必要に応じて対象タブの「同時再生」もOFFにします。

OBSなどにも音声を選ぶ機能があります。このツールは、オーバーレイやキーで取得元を切り替え、出力先をON/OFFしたいときに使います。取得元は一度に一つです。

起動する

インストーラーで導入した場合は、スタートメニューから「VoiceMixerSpkRouter」を起動します。

ZIP版の場合は、ZIPを右クリックして「すべて展開」を選び、書き込み可能なフォルダーへ展開してから、VoiceMixerSpkRouterフォルダーのvoicemixer-spk.exeをダブルクリックします。ZIPの中から直接実行しないでください。

  1. 初回は設定画面が開きます。取得は停止、出力1・2は両方OFFです。
  2. 入力スピーカー・アプリ・ブラウザの必要なものを設定し、出力1・2の再生デバイスを選びます。使用する出力の「有効」をONにして「適用」を押します。
  3. オーバーレイ、またはShift+F1／F2／F3で取得元を選びます。選択中のキーをもう一度押すと停止、Shift+F4は常に停止です。キーは設定で変更できます。

ブラウザ音声を使う

拡張のインストール案内から、同梱のbrowser-extensionをChrome／Edgeへ読み込みます。次に接続設定でポート・認証トークン・ストリームキーを合わせ、対象タブの音声キャプチャを開始します。

設定と終了

設定はEXEと同じフォルダーのspk-settings.jsonへ保存します。認証トークンを含むので、このファイルを共有しないでください。初回起動時に利用者ごとの値を生成します。

設定画面の「閉じる」は常駐を続けます。アプリを終了する場合は通知領域のアイコンを右クリックし「終了」を選びます。設定はトレイまたはオーバーレイから再び開けます。

更新する

アプリを終了して設定ファイルを退避します。インストーラー版は新しいsetupを実行し、同じ導入先へ更新します。ZIP版は新しいZIPの内容を同じフォルダーへ上書きします。配布物には設定ファイルが入っていないため、保存済み設定は残ります。ブラウザ拡張も更新する場合は、送信を止めてから拡張の管理画面で再読み込みします。
