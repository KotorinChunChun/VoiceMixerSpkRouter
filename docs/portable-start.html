VoiceMixerSpkRouterの使い方

Windows 11の64ビット版向けです。Rust・Node.js・PowerShell 7のインストールは不要です。

起動する

  1. ZIPを右クリックして「すべて展開」を選び、書き込み可能なフォルダーへ展開します。
  2. VoiceMixerSpkRouterフォルダーのvoicemixer-spk.exeをダブルクリックします。ZIPの中から直接実行しないでください。
  3. 初回は設定画面が開きます。取得は停止、出力1・2は両方OFFです。
  4. 入力スピーカー・アプリ・ブラウザの必要なものを設定し、出力1・2の再生デバイスを選びます。使用する出力の「有効」をONにして「適用」を押します。
  5. オーバーレイ、またはShift+F1／F2／F3で取得元を選びます。選択中のキーをもう一度押すと停止、Shift+F4は常に停止です。キーは設定で変更できます。

ブラウザ音声を使う

拡張のインストール案内から、同梱のbrowser-extensionをChrome／Edgeへ読み込みます。次に接続設定でポート・認証トークン・ストリームキーを合わせ、対象タブの音声キャプチャを開始します。

設定と終了

設定はEXEと同じフォルダーのspk-settings.jsonへ保存します。認証トークンを含むので、このファイルを共有しないでください。初回起動時に利用者ごとの値を生成します。

設定画面の「閉じる」は常駐を続けます。アプリを終了する場合は通知領域のアイコンを右クリックし「終了」を選びます。設定はトレイまたはオーバーレイから再び開けます。

更新する

アプリを終了して設定ファイルを退避し、新しいZIPの内容を同じフォルダーへ上書きします。ZIPには設定ファイルが入っていないので、保存済み設定は残ります。ブラウザ拡張も更新する場合は、送信を止めてから拡張の管理画面で再読み込みします。
